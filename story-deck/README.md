# Interview Copilot story deck

Self-contained presentation bundle. Keep every file in this directory together.

- `index.html` — presentation entry point
- `interview-copilot-live.html` — scrollable live-workspace artifact
- `interview-copilot-report.html` — scrollable generated report
- `interview-evidence-animation.mp4` — 15-second evidence-base animation

Open `index.html` directly, or serve the repository root and visit `/story-deck/`.
Use the arrow keys to navigate and `F` for fullscreen. Click inside either embedded
artifact to scroll it; click outside before navigating slides.
